# 浮启 Floaty V2 需求规格说明书

> 本版为 V2.3（2026-10-18 F7 叶形图标与悬停动效修订），变更明细见文末「10. 修订记录」。

## 1. 版本概述

V1 已完成"悬浮球 + 快捷启动"最小闭环（F1-F6），手动验收基本符合要求。V2 在不改变产品定位的前提下做两件事：

- **体验与视觉升级**：建立统一的视觉语言，重绘悬浮球图标，美化右键菜单、展开面板与管理窗口，解决 V1 界面"素、宽、图标糙"的问题。
- **能力补全**：新增分组、排序、贴边吸附、多显示器适配、拖拽快速添加、轻量外观设置，兑现 V1 spec 第 6 章中已承诺延后且本次确认纳入的功能。

V2 不做的：程序启动参数、以管理员身份启动（仍延后至 V3）。

## 2. 术语定义

- **浮青**：V2 建立的视觉语言名称，取"悬浮之青（绿）"之意，贯穿悬浮球、面板、菜单、对话框全部界面。
- **设计令牌**：统一的色值、字号、圆角、间距规格，所有界面必须引用同一套令牌，不允许各窗口自定义色值。
- **分组**：快捷项的归类容器，如"工作""工具"。每个快捷项必须且只能属于一个分组。
- **默认分组**：系统内置的初始分组，名称为"默认分组"，不可删除、不可重命名；未指定分组的快捷项归入该组。
- **分区标题**：展开面板中分组的标题分隔行，仅用于展示与归类，本身不是快捷项、不可启动。
- **跑马灯滚动**：行文字过长被截断时，鼠标悬停该行，文字在水平方向循环滚动以显示完整内容。
- **吸附距离**：拖动悬浮球松手时，球边缘距屏幕边缘小于该距离则自动贴边。
- **外观设置**：V2 新增的轻量设置项集合，共三项：悬浮球大小、展开面板背景不透明度（0-100%）、展开面板最大宽度（80-480px）。

## 3. 设计语言「浮青」（全窗口统一规范）

本章为 F7-F9、F12-F13 的共同依据，任何界面美化不得偏离本章规格。

### 3.1 设计理念

- **浮**：界面元素始终有轻盈、悬浮感，通过半透明、圆角、柔和描边表达，不使用厚重阴影与拟物质感。
- **启**：启动、向上。悬浮球图标与展开方向均含"上浮"意象；主色使用绿色系，取"新叶初启、安静常在"的感觉，呼应软件名"浮启"。
- **简洁**：每屏只出现必要元素；线性图标、克制配色、充足留白；不使用渐变装饰块、表情符号、卡通插画。

### 3.2 色彩令牌

| 令牌 | 色值 | 用途 |
|------|------|------|
| 主色 | #2E8B6B（竹绿） | 悬浮球主色、选中态、主按钮、分区标题文字 |
| 主色悬停 | #3AA47E | 主按钮悬停、行悬停强调 |
| 主色按下 | #26735A | 按下态 |
| 浅绿底 | #E5F2EB | 菜单/列表项悬停背景、选中行背景 |
| 面板底色 | #F7FBF8（青瓷白） | 菜单、面板、对话框背景基色 |
| 主文字 | #24342D | 标题、正文 |
| 次文字 | #6B7B73 | 副标题、说明文字、目标摘要 |
| 描边 | #D6E2DB | 窗口、按钮、分隔线描边 |
| 危险色 | #C0504D | 仅用于删除等破坏性操作的文字/按钮，克制使用 |

悬浮球图标为叶形：叶片使用绿色线性渐变（叶根深绿 #1E5F44、中部竹绿 #2E8B6B、叶尖浅绿 #8AD3A8）；叶梗自叶尖起 0%~66% 恒定纯白，66%~92% 渐变为深绿 #1E5F44，92% 以后（叶外短柄）恒定深绿。

列表行（管理窗口右栏快捷项行与左栏分组行、展开面板行）的状态色全窗口统一，只允许以下组合：

| 状态 | 背景 | 文字 |
|------|------|------|
| 普通 | 透明 | 主文字 #24342D |
| 悬停 | 浅绿底 #E5F2EB | 主文字 #24342D |
| 选中 | 浅绿底 #E5F2EB | 主色 #2E8B6B，加粗 |

任何状态下文字与其背景必须对比清晰、可读；不允许选中态文字变白或变浅，也不允许出现系统默认的蓝底白字。

### 3.3 字体与字号

- 字体统一为 Microsoft YaHei UI（Windows 系统自带字体，无版权问题）。
- 悬浮球无文字；面板与菜单正文 9pt；对话框标题 12pt；分区标题 9pt 主色；说明文字 8pt 次文字色。

### 3.4 圆角与间距

- 悬浮球：正圆。
- 菜单、展开面板、设置对话框：圆角 8px。
- 管理窗口：圆角 8px；内部按钮圆角 6px；列表行圆角 6px。
- 间距采用 4 的倍数栅格：4 / 8 / 12 / 16 px。

### 3.5 图标规范

- 全部图标为项目自绘线性 SVG 源文件，随程序内置，版权归本项目所有；不得使用系统品牌图标、第三方图标库、网络图片或任何来源不明的素材。
- 统一规格：24x24 视口，1.5px 等粗描边，圆角线帽与圆角转角，透明背景，单色（使用时按场景赋主文字色或白色）。
- 界面内的功能图标（添加文件、添加文件夹、添加网址、上移、下移、编辑、删除、新建分组、设置、管理、退出、空状态图形）全部遵循同一套规格。

### 3.6 半透明规范

- 仅展开面板使用半透明背景（见 F12），其他窗口保持不透明以保证可读性。
- 半透明指窗口背景填充使用带透明度的青瓷白，文字、图标、行悬停/选中底色与 1px 描边均不做透明处理。
- 不透明度可在外观设置中调整（见 F13），范围 0-100%，步进 5%，默认 88%。
- 0% 表示面板背景完全透明（可直接透过面板看到桌面），但描边、文字与图标仍实色显示，面板外形可辨、内容可读、所有交互照常；100% 表示背景完全不透明。

### 3.7 品牌标识规范

- 品牌中文名为"浮启"；F7 重绘的悬浮球图形即品牌图形标识，品牌头直接等比缩小使用该图形，不另设第二套 Logo，不引入额外图片素材。
- **重型对话框品牌头**：管理窗口（F9）与设置对话框（F13）窗口内容区顶部设置统一品牌头——左侧为 20px 悬浮球图形，右侧纵向两行：主行"浮启"（12pt、主色、加粗），次行为功能名（9pt、次文字色，管理窗口为"管理快捷项"，设置对话框为"设置"）；品牌头与下方内容之间用 1px 描边色分隔线。
- **轻型对话框标题前缀**：编辑快捷项、添加网址、名称确认等轻型对话框，以及全部提示框、确认框，系统标题栏文字统一以"浮启"开头：带功能的为"浮启 · 功能名"（如"浮启 · 编辑快捷项"），纯提示/确认框标题仅为"浮启"。
- 右键菜单与展开面板不出现品牌文字：菜单保持三项极简形态；展开面板为高频轻量弹出，品牌由其旁的悬浮球图形承载。
- 品牌头不承担任何交互功能（不可点击、不做关于弹窗入口）。

## 4. 技术选型

沿用 V1 技术栈：C++17 + Qt 6.8 Widgets + CMake + MSVC，配置仍为 `%APPDATA%\Floaty\config.json`（QJsonDocument）。V2 新增：

| 项目 | 选型 | 理由 |
|------|------|------|
| 图标资源 | 自绘 SVG + Qt 资源系统（qrc） | 矢量无损、可统一着色、随单文件 exe 分发，保证版权清洁 |
| 界面样式 | 全局统一样式表 + 设计令牌常量 | 全部窗口一处维护，消除分散的内联样式 |
| 半透明窗口 | Widgets 自绘半透明背景 | 不依赖特定 Windows 版本的特效接口，Windows 10/11 表现一致 |
| 拖放添加 | Qt 拖放事件 | 框架内建能力，无需系统钩子 |

## 5. V2 功能需求

### F7 悬浮球图标重绘

- **需求描述**：按「浮青」语言重绘悬浮球为叶形图标。图标整体为一片向右上舒展的叶子：实心叶片使用绿色线性渐变（叶根深绿 #1E5F44 → 中部竹绿 #2E8B6B → 叶尖浅绿 #8AD3A8）；叶梗为一条完整曲线（外段短柄与内段中脉无缝相连），自叶尖起 0%~66% 恒定纯白，66%~92% 渐变为深绿 #1E5F44，叶外短柄与叶根同色，浅色背景下仍清晰可辨。整体表达"新叶初启、悬浮向上"，呼应"浮启"。保持无边框、置顶、不抢焦点的 V1 行为不变。
- **悬停动效**：鼠标移入悬浮球时，叶片三色渐变档位与梗根深绿端整体向浅绿方向平滑过渡（叶根→#3AA47E、中部→#55BD95、叶尖→#B4E6CB），移出时过渡回常态；过渡时长约 160ms，缓出曲线；过渡中途反向（快速移进移出）时从当前进度平滑折返，不跳变。
- **验收标准**：
  - 当启动应用，则悬浮球显示为叶形图标，无标题栏、无系统边框，视觉风格与面板、菜单同色系。
  - 当观察图标细节，则叶片为绿色渐变、叶梗为白绿渐变，整体包含明确的向上/上浮方向感，不含文字、字母、emoji 或写实图案。
  - 当在浅色与深色桌面壁纸上观察，则叶形轮廓与梗部均可清晰辨认；浅色壁纸下叶外短柄为深绿、不消失。
  - 当鼠标移入悬浮球，则叶片在约 0.2 秒内平滑高亮为浅绿；移出则平滑恢复常态色；快速往返移动时不出现颜色跳变。
- **边界说明**：V2 不支持用户自定义悬浮球图标；球内不放快捷项数量等动态信息；不做呼吸、旋转等动画。

### F8 悬浮球右键菜单样式与图标

- **需求描述**：右键悬浮球弹出的菜单按「浮青」语言重绘：圆角 8px、青瓷白底、细描边、菜单项悬停为浅绿底；每项左侧带一枚同规格自绘线性图标。菜单包含三项，自上而下为："管理快捷项"（清单线条图标）、"设置"（滑块线条图标）、"退出"（门与向外箭头线条图标）。右键不触发展开面板的 V1 行为不变。
- **添加"设置"项的原因**：F13 外观设置需要入口；这是 V2 对 V1"菜单恰含两项"规则的有意变更。
- **验收标准**：
  - 当右键悬浮球，则弹出菜单恰含"管理快捷项""设置""退出"三项，每项左侧均有线性风格图标，三枚图标线宽、视口、配色一致。
  - 当鼠标在菜单项间移动，则悬停项出现浅绿底，其余项无底色；菜单圆角、底色、描边与展开面板视觉一致。
  - 当右键悬浮球，则不触发展开面板；点击菜单外区域则菜单关闭。
  - 当点击三项，则分别打开管理窗口、打开设置对话框、退出应用。
- **边界说明**：菜单不增加"关于""帮助"等其他入口；不使用系统默认菜单外观；图标不使用任何第三方素材。

### F9 管理窗口视觉升级

- **需求描述**：管理窗口按「浮青」语言重新设计为双栏布局：顶部为统一品牌头（20px 悬浮球图形 + "浮启" + "管理快捷项"功能名，见 3.7），品牌头下方为双栏内容区；左栏为分组栏（与 F10 联动），分组行（含"全部快捷项"汇总行）的普通/悬停/选中状态色遵循 3.2 列表行状态色统一规则：选中行为浅绿底加主色加粗文字，与右栏快捷项行的选中态完全一致；右栏为当前分组下的快捷项列表，每行显示图标、名称（主文字）、目标摘要（次文字，网址显示 URL、文件显示完整路径）；右侧操作按钮区纵向排列"添加文件""添加文件夹""添加网址""上移""下移""编辑""删除"，底部为"关闭"。主操作（添加类）使用主色实心按钮，其余操作使用描边次按钮，删除使用危险色文字按钮。列表为空时显示自绘线性空状态图形与一行引导文字（"还没有快捷项，点击上方按钮添加"）。
- **验收标准**：
  - 当打开管理窗口，则窗口顶部显示品牌头：悬浮球小图形、主色加粗的"浮启"、次文字"管理快捷项"，品牌头与内容区间有分隔线；窗口系统标题栏文字为"浮启 · 管理快捷项"。
  - 当打开管理窗口，则窗口为圆角青瓷白底色，双栏、按钮区齐备，字体、配色、圆角、间距与第 3 章令牌一致。
  - 当列表有快捷项，则每行显示图标、名称、目标摘要，行悬停为浅绿底，选中行为浅绿底加主色文字。
  - 当在左栏分组行之间切换选中，则当前选中分组行（含"全部快捷项"）为浅绿底加主色加粗文字，文字清晰可读；悬停行为浅绿底加主文字色；左栏与右栏选中态配色一致。
  - 当列表为空，则显示空状态图形与引导文字，不显示空白白框。
  - 当逐项核对按钮样式，则添加类按钮为主色实心，上移/下移/编辑/关闭为描边按钮，删除为危险色文字按钮。
- **边界说明**：管理窗口不调整 V1 已有的添加/编辑/删除业务规则（白名单、类型自动识别、名称确认、删除二次确认均保留，按新样式呈现）。

### F10 分组管理

- **需求描述**：快捷项按分组组织。系统内置"默认分组"（不可删除、不可重命名）；用户可新建、重命名、删除自定义分组。分组管理在管理窗口左栏完成：左栏列出全部分组及"全部快捷项"汇总视图，底部有"新建分组"按钮；分组行支持右键菜单"重命名""删除"（默认分组不显示该菜单）。删除自定义分组时，该组下的快捷项全部移入默认分组，不允许快捷项无分组。添加快捷项时加入当前在左栏选中的分组，编辑快捷项时可在编辑对话框的分组下拉框中调整归属。展开面板以"列表分区显示"呈现：同一个滚动列表内按分组依次排列，每组先显示主色分区标题（分组名），标题下方为该组快捷项行，组间留 8px 间距；空分组不在面板中显示。
- **验收标准**：
  - 当新建一个分组并向其中添加快捷项后展开面板，则该分组以分区标题形式出现，其下显示组内快捷项；默认分组与该分组在同一列表内上下排列。
  - 当某分组没有快捷项时展开面板，则该分组的分区标题不出现。
  - 当双击分区标题行，则不启动任何目标，标题无双击反馈之外的反应。
  - 当在编辑对话框中把一个快捷项改到另一分组并保存，则该项从原分组分区消失、出现在目标分组分区，全局面板与管理窗口同步。
  - 当删除一个含有快捷项的自定义分组并确认，则分组消失，其下快捷项全部出现在默认分组中，快捷项本身不丢失。
  - 当尝试操作默认分组，则不存在删除与重命名入口。
  - 当重命名分组后展开面板，则分区标题显示新名称。
- **边界说明**：分组不支持嵌套（只有一级）；不支持分组排序，分组按"默认分组在前、自定义分组按创建时间"排列；分组不支持自定义颜色与图标；分区标题不参与双击启动。

### F11 快捷项排序

- **需求描述**：管理窗口中支持调整同一分组内快捷项的顺序，提供两种方式：列表内直接拖拽行到目标位置；选中行后点击"上移""下移"按钮。展开面板严格按配置中的顺序显示。
- **验收标准**：
  - 当把一行拖拽到同组另一位置并松开，则行落到目标位置，其余行顺移。
  - 当选中首行点击"上移"或末行点击"下移"，则顺序不发生变化（边界处不回绕）。
  - 当排序后退出应用并重新启动，则展开面板分区内的顺序与排序后一致。
  - 当在"全部快捷项"汇总视图下，则排序操作不可用（按钮置灰、列表不可拖拽），排序只能在具体分组视图内进行。
- **边界说明**：不支持跨分组拖拽移动快捷项（跨分组通过编辑对话框修改归属，见 F10）；不支持自动排序（按名称、按类型等）；分区标题不可拖动。

### F12 展开面板视觉升级、宽度自适应与跑马灯

- **需求描述**：展开面板按「浮青」语言重绘：圆角 8px、半透明青瓷白背景（不透明度取外观设置值，默认 88%）、细描边；面板内为分区列表（见 F10），快捷项行高 34px、行圆角 6px、悬停浅绿底。面板宽度严格按内容自适应，宽度口径（逻辑像素）为：

  > 面板宽 = 12（左内边距）+ 最宽内容行宽 + 12（右内边距），再夹取到 [80px, 面板最大宽度设置值]（见 F13，默认 320px）。

  其中内容行宽取以下两者在全部可见分组中的最大值：
  - 快捷项行：2（行左缘）+ 20（图标）+ 8（图标与文字间距）+ 名称文字宽 + 2（行右缘）；
  - 分区标题行：2（行左缘）+ 标题文字宽 + 2（行右缘）。

  即面板左右留白恒为内边距 12px、行与内容容器之间 2px，不允许出现口径之外的多余空白。名称在夹取后的行内剩余宽度仍显示不下时截断；鼠标悬停该行，名称文字在该行内做跑马灯滚动，循环显示完整名称，鼠标移开后文字立即复位为起始截断状态。分区标题超过最大宽度时以尾部省略号截断（标题不做跑马灯）。内容总高超过面板高度上限而出现垂直滚动条时，滚动条为悬浮在内容右缘内侧的纤细半透明样式，不占用面板宽度与名称可用宽度——无论滚动条是否出现，面板宽度与名称截断位置保持一致。面板为空（无任何快捷项）时，宽度同样按内容计算且不小于 80px，不使用固定更宽值。V1 的单击展开、点外收起、再点球收起、双击启动、仅双击不单击、启动后收起、目标不存在提示、超量滚动等行为全部保留。
- **验收标准**：
  - 当展开面板，则面板为半透明圆角窗口，能隐约看到面板后的桌面或窗口，同时深色与浅色壁纸上文字均可清晰辨认；风格与右键菜单、悬浮球一致。
  - 当快捷项名称都较短，则面板宽度恰好包裹内容：左右仅见 12px 内边距与 2px 行缘，无口径之外的多余空白条，明显窄于 V1 的固定宽面板，且不小于 80px。
  - 当存在超长名称的快捷项，则面板宽度不超过最大宽度设置值（默认 320px），该行名称以截断方式显示，不撑宽窗口、不换行；超长分区标题以尾部省略号截断。
  - 当快捷项数量多到内容超高出现垂直滚动条，则面板宽度与名称截断位置相对滚动条出现前不发生变化，滚动条悬浮覆盖在右缘内侧。
  - 当没有任何快捷项时展开面板，则空状态面板宽度按内容计算且不小于 80px，不出现固定的多余宽度。
  - 当鼠标悬停在被截断的行上，则名称开始水平滚动并能看到完整名称；鼠标移开则停止滚动并复位。
  - 当鼠标悬停在未被截断的行上，则文字不发生滚动。
  - 当应用处于静置状态、无鼠标悬停，则不产生持续动画与持续 CPU 消耗（跑马灯仅对当前悬停行运行）。
- **边界说明**：面板最大宽度为 F13 外观设置项（默认 320px，可调），不再是固定规格；目标路径不参与宽度计算（仅作为编辑依据与管理窗口摘要）；跑马灯期间不弹文字气泡提示；面板不做尺寸拖拽手柄。

### F13 外观设置（轻量可调）

- **需求描述**：右键菜单新增"设置"项打开设置对话框，对话框顶部为统一品牌头（悬浮球图形 + "浮启" + "设置"，见 3.7），提供三项调节：
  1. **悬浮球大小**：小 40px / 标准 48px / 大 56px 三档单选，默认标准；
  2. **展开面板背景不透明度**：0%-100% 滑块，步进 5%，默认 88%；
  3. **展开面板最大宽度**：80-480px 滑块，步进 20px，默认 320px（即 F12 的最大宽度夹取值）。

  三项调节在对话框打开期间实时预览，且预览作用域严格分离、互不牵连：
  - 切换球大小档：仅悬浮球立即变为对应尺寸，以当前球心为锚点缩放（球心不动），越出屏幕可视区才夹取；不重绘面板透明度，不改变面板宽度；
  - 拖动不透明度滑块：仅已展开面板的背景透明度实时跟随；悬浮球的位置与尺寸保持完全不变，不重算球几何、不重新定位、不触发吸附；
  - 拖动最大宽度滑块：仅已展开面板按新上限立即重新计算宽度（宽度收窄或放宽，内容与球均不动）；面板未展开时下次展开即按新值。

  所有预览值在确定前不写盘。点击"确定"保存三项并关闭；点击"取消"关闭，并把三项外观值、预览期间悬浮球的尺寸与位置全部还原为打开对话框前的状态（打开前球若处于贴边停靠位，取消后仍恢复到该停靠位与 8px 间隙，不得留下球心锚定产生的偏移）。设置持久化在配置文件中，重启后保持。
- **验收标准**：
  - 当打开设置对话框，则顶部显示与管理窗口同规格的品牌头（功能名为"设置"），系统标题栏文字为"浮启 · 设置"；对话框含球大小、不透明度、面板最大宽度三组控件，各控件实时显示当前值。
  - 当切换悬浮球大小档位，则悬浮球立即变为对应尺寸（40/48/56px 正圆，图形等比不变形），球心保持不动；变大后超出屏幕可视区才夹取。
  - 当在球处于屏幕中部、贴边停靠、面板展开/收起等任一状态下仅拖动不透明度滑块，则悬浮球窗口的位置与尺寸在拖动全程逐次比较均无任何变化。
  - 当拖动不透明度滑块，则处于展开状态的面板背景透明度实时跟随；停在 0% 时背景完全透明但描边、文字、图标实色可辨且面板可正常操作，停在 100% 时完全不透明，步进为 5%，拖不到 0 以下或 100 以上。
  - 当拖动面板最大宽度滑块，则已展开面板宽度在 80-480px 范围内按 20px 步进实时收窄/放宽并始终夹取：短内容不小于 80px，长内容不超过当前滑块值；球与其他元素不发生位移。
  - 当点击取消后重新打开设置对话框，则三组控件显示修改前的值，悬浮球尺寸与位置（含贴边停靠间隙）、面板透明度与最大宽度均已还原，配置文件未改变。
  - 当设置完成后退出并重启应用，则球大小、面板不透明度与面板最大宽度均为上次保存的值。
- **边界说明**：V2 设置仅含这三项；不提供主题色、字体、展开方向、自定义图标等设置；对话框不另设重置按钮（默认档位即标准/88%/320px，取消即可还原）。面板最大宽度的调节范围 80-480px、步进 20px 为本版采用规格（80 为容纳一个正文字符的面板宽度向上对齐到步进倍数，480 可容纳约 30 个汉字且不超过主流屏幕宽度的四分之一）。

### F14 贴边吸附

- **需求描述**：拖动悬浮球松手时，若球边缘距其所在屏幕的任一可视边缘小于 24px（吸附距离），则悬浮球自动贴齐该边缘停靠，停靠后球与屏幕边缘保留 8px 间隙；同时靠近两条边缘（四角区域）时两边同时贴齐。吸附仅在松开鼠标时发生一次位置修正，拖动过程中球体严格跟随鼠标、不提前跳动。吸附后的位置立即持久化。
- **验收标准**：
  - 当把球拖到距左边缘 24px 以内松开，则球自动贴到左侧停靠位（距左边缘 8px），垂直位置保持松手点不变。
  - 当把球拖到屏幕四角区域松开，则球同时贴齐相邻的两条边缘。
  - 当把球拖到屏幕中部（四边均大于 24px）松开，则球停在松手位置，不发生任何位置修正（不吸附）。
  - 当拖动过程经过边缘附近但未松开，则球始终跟随鼠标，不产生吸附跳动。
  - 当吸附后再次按住球向屏幕中部拖动，则球可以自由离开停靠位。
  - 当吸附后退出重启，则球恢复在吸附后的停靠位置。
- **边界说明**：吸附仅做边缘对齐，不做隐藏缩出屏幕、不做边缘悬停回弹；吸附距离 24px 与停靠间隙 8px 为固定规格，不可配置；此条取代 V1 用例 TC-F1-05"不吸附"的预期。

### F15 多显示器精细适配

- **需求描述**：悬浮球可在系统配置的任意显示器之间拖动，展开方向、边界夹取、贴边吸附均按悬浮球当前所在显示器的可用区域（排除任务栏）计算，而非固定按主显示器。重启后悬浮球恢复到上次所在显示器的对应位置。
- **验收标准**：
  - 当把悬浮球从主显示器拖到副显示器任意位置松开，则球可以停留在副显示器上，展开面板在副显示器、球旁出现且完整不越界。
  - 当球停在副显示器时触发贴边吸附，则吸附参照副显示器的边缘，与主显示器无关。
  - 当球位于副显示器时退出应用、副显示器仍连接、再启动，则球出现在副显示器的上次位置。
  - 当配置中记录的显示器在启动时已不存在（如副屏被拔走），则球出现在主显示器的默认位置，应用正常启动不报错。
  - 当不同显示器分辨率或缩放不同，则球尺寸、面板尺寸与内容不出现错位、裁切或模糊。
- **边界说明**：不支持"每块显示器一个独立悬浮球"，全应用始终只有一个球；不支持跨显示器分辨率差异导致的位置比例换算，按记录位置与当前所在屏幕夹取显示。

### F16 拖拽文件快速添加

- **需求描述**：在系统资源管理器中把文件或文件夹拖入悬浮球，或拖入展开面板后松开，即可快速添加快捷项：拖入时悬浮球/面板出现主色描边高亮反馈，松开后白名单内的目标加入指定分组——拖到面板中某分组的分区标题或其组内行区域，加入该分组；拖到悬浮球上，或拖到面板空白区域，加入默认分组。单个文件拖入时弹出名称确认框（预填默认名，规则与 V1 管理窗口一致）；多个文件一次拖入时按默认名称全部直接加入，不逐个弹窗。白名单外类型按 V1 规则拒绝并提示"不支持的文件类型"，其中混有合法与非法文件时，合法文件正常加入，非法文件逐一列出提示。URL 不能拖入，仍通过管理窗口"添加网址"录入。
- **验收标准**：
  - 当把一个白名单内文件拖到悬浮球上（拖动悬停期间），则悬浮球出现主色高亮反馈，松开后弹出名称确认框，确认后该快捷项出现在默认分组分区。
  - 当把文件拖到展开面板中某分组的分区上松开，则该快捷项归属该分组。
  - 当一次拖入 3 个合法文件，则不经名称弹窗，三项均以默认名称直接加入，类型按扩展名自动识别，图标正常显示。
  - 当拖入 .reg、.ps1 等白名单外文件，则出现"不支持的文件类型"提示，列表面板不新增该项。
  - 当一批拖入文件中同时包含合法与非法文件，则合法项加入成功，非法项被提示拒绝。
  - 当拖入操作进行中按 Esc 或拖出区域松开，则不添加任何内容，界面恢复常态。
- **边界说明**：仅接受操作系统文件拖放（含 .lnk 快捷方式文件与文件夹），不接受拖入文本、URL、应用商店快捷方式；拖放添加不改变既有双击启动逻辑；拖入过程不启动被拖文件。

## 6. 配置文件变更

- 配置文件路径与 JSON 格式不变（`%APPDATA%\Floaty\config.json`），结构扩展为：快捷项增加分组归属与组内顺序；新增分组列表；新增外观设置（球尺寸档位、面板不透明度 0-100、面板最大宽度 80-480）；多显示器场景下位置记录包含所在显示器信息。外观设置 JSON 形如 `"appearance": { "ballSize": 48, "opacity": 88, "panelMaxWidth": 320 }`。
- V2 直接采用新结构，不做 V1 配置的迁移与兼容读取。
- 不写注册表的约束不变。

## 7. 非功能需求

V1 非功能指标全部延续，另增补视觉与交互指标：

- **内存占用**：稳态运行（悬浮球收起、无交互、无悬停动画）进程内存不超过 50MB。
- **启动速度**：冷启动到悬浮球可见不超过 1 秒（机械硬盘环境除外）。
- **单实例**：同一时刻只允许一个 Floaty 进程。
- **安装形态**：绿色免安装目录（exe + Qt 运行库 + VC 运行库 + 内置 SVG 资源），不写注册表，删除目录即卸载。
- **系统要求**：Windows 10 及以上。
- **风格一致性**：悬浮球、展开面板、右键菜单、管理窗口、设置对话框的色值、字体、圆角、间距全部来自第 3 章设计令牌；全部图标符合同一 SVG 规格；全部对话框按 3.7 展示"浮启"品牌标识（重型对话框品牌头、轻型对话框标题前缀、提示框标题统一为"浮启"）；验收时逐窗口比对，不得出现令牌外的色值、控件默认灰色外观或英文 "Floaty" 字样。
- **版权清洁**：随程序分发的全部视觉资产（SVG 图标等）均为项目自有源文件；不附带任何第三方图库、字体或图片素材。
- **动画性能**：跑马灯滚动仅在鼠标悬停的行上运行，移开即停；静置状态下不存在持续运行的动画定时器。

## 8. V3 及以后

以下功能本次明确不做：

- 程序快捷项附加启动参数、以管理员身份启动（来源：V1 spec 第 6 章，本次确认继续延后）
- 展开方向可配置、自定义主题色、用户自定义图标（外观深度自定义，超出"轻量可调"范围）
- 分组嵌套、分组排序与分组着色
- 快捷项搜索、按名称/类型自动排序
- 云同步、多套配置

当前无待确认问题。三项关键决策已确认：补全范围为贴边吸附 + 多显示器 + 拖拽快速添加（不含启动参数/管理员身份）；外观自定义为轻量可调（最初为球大小、面板透明度两项，V2.1 增补面板最大宽度，见 F13）；展开面板分组形态为列表分区显示。
