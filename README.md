浮启 · Floaty
一个轻量的 Windows 桌面悬浮窗启动器。

浮启 常驻在桌面边缘，把常用程序、文档、文件夹收进一个小小的悬浮窗里。点一下就启动，不用再去翻开始菜单、找快捷方式、开资源管理器。

它解决什么
桌面快捷方式一多就乱，任务栏又放不下几个。浮启给你一个始终在手边、又不占地方的启动入口——需要时点开，不需要时缩成一个小球，安静待在角落。

核心特性
悬浮常驻 — 窗口置顶，不抢焦点，可自由拖动到屏幕任意位置

快捷启动 — 支持程序、文档、文件夹、网址，点一下即打开

分组管理 — 按类别收纳，程序、文档、工具各归各的

轻量无感 — 内存占用小，启动快，不写注册表垃圾

可自定义 — 图标、大小、透明度、展开方向都能调

名字含义
浮 —— 悬浮在桌面之上，随手可及。
启 —— 启动，一键直达。
