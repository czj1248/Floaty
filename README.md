浮启 · Floaty
一个轻量的 Windows 桌面悬浮窗启动器。

浮启常驻在桌面边缘，把常用程序、文档、文件夹、网址收进一片小小的"叶子"里。点一下就展开，双击即启动，不用再去翻开始菜单、找快捷方式、开资源管理器。

它解决什么
桌面快捷方式一多就乱，任务栏又放不下几个。浮启给你一个始终在手边、又不占地方的启动入口——需要时点开，不需要时缩成一片小叶，安静待在角落。

快速上手
1. 启动 Floaty.exe，桌面边缘出现一片绿色小叶（悬浮球）。
2. 添加内容有两种方式：
   - 直接把文件、文件夹拖到悬浮球上，自动加入默认分组；
   - 右键悬浮球选"管理快捷项"，在管理窗口里添加文件、文件夹或网址，并按分组归类。
3. 左键单击悬浮球展开快捷列表面板，双击列表项即可启动；文件类条目用系统默认方式打开。
4. 右键悬浮球可调出菜单：管理快捷项、设置、退出。

核心特性
悬浮常驻 — 置顶显示，不抢焦点；可拖动到任意位置，松手自动贴边吸附；多显示器下跟随所在屏幕。

快捷启动 — 支持程序、文档、文件夹、网址；单击展开面板，双击启动，启动后面板自动收起。

分组与排序 — 快捷项按分组收纳，面板分区显示；管理窗口内可拖拽或按钮调整组内顺序。

拖放即加 — 从资源管理器把文件拖到悬浮球上即可快速收录，无需打开管理窗口。

外观可调 — 悬浮球大小三档（40/48/56px）、面板不透明度（0-100%）、面板最大宽度（80-480px），设置实时预览，取消即还原。

细腻视觉 — 悬浮球为「浮青」叶形图标，悬停时叶片平滑高亮为浅绿；面板半透明、超长名称悬停跑马灯滚动。

轻量干净 — 内存占用约 27MB，启动快；配置写入 %APPDATA%\Floaty\config.json，不写注册表；单实例运行，重复启动只会唤出已有实例。

常用操作一览
- 单击悬浮球：展开 / 收起快捷列表面板
- 按住拖动：移动悬浮球，松手自动贴边（距边缘 24px 内触发，停靠留 8px 间隙）
- 双击列表项：启动程序 / 打开文件、文件夹、网址
- 右键悬浮球：管理快捷项 / 设置 / 退出
- 拖文件到悬浮球：快速添加到默认分组

名字含义
浮 —— 悬浮在桌面之上，随手可及。
启 —— 启动，一键直达。
